# Домашние задания 5 и 6 — Исследовательский анализ данных

## Обзор

Исследовательский анализ данных (EDA) набора данных об играх Steam, включающий оценку качества данных, анализ распределений, пропущенных значений, выбросов, категориальных переменных и корреляций.

Домашнее задание 6 расширяет первоначальный анализ за счёт использования продвинутых визуализаций с помощью **Plotly Express**.

## Структура проекта
```
5/
├── datasets/          # Файлы набора данных (не включены в Git)
├── notebooks/
│   └── EDA.ipynb      # Анализ для домашних заданий 5 и 6
├── .gitignore
├── requirements.txt
└── README.md
```

## Требования

Установка зависимостей:
```
pip install -r requirements.txt
```

## Запуск ноутбука

Откройте `notebooks/EDA.ipynb` в Jupyter Notebook или Cursor.

Файлы набора данных необходимо разместить в директории `datasets/`.

## Визуализации

Домашнее задание 6 включает интерактивные визуализации Plotly Express, настроенные для статического отображения в формате PNG, что обеспечивает их корректное отображение на GitHub.
