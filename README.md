# Домашнее задание 5 — Исследовательский анализ данных

Проведён исследовательский анализ данных (EDA) набора данных об играх Steam.

### Набор данных

- **Источник:** [Steam Games Dataset – Kaggle](https://www.kaggle.com/datasets/fronkongames/steam-games-dataset)
- **Количество записей:** 125 855
- **Количество столбцов:** 40

### Содержание

- `notebooks/EDA.ipynb` — Полный исследовательский анализ данных, включающий оценку качества данных, анализ пропущенных значений, распределений, выбросов и корреляций.

Файлы набора данных исключены из репозитория.
