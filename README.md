# Домашнее задание 8 — ETL-процесс обработки данных об играх Steam

## Обзор

Данный проект реализует ETL-процесс (Extract, Transform, Load) для подготовки данных об играх Steam и загрузки до 100 проверенных записей в удалённую базу данных PostgreSQL.

ETL-процесс реализован в виде самостоятельного Python-пакета.

## Структура проекта

```text
8/
├── src/
│   └── etl/
│       ├── __init__.py
│       ├── extract.py
│       ├── transform.py
│       ├── validate.py
│       ├── load.py
│       └── main.py
├── tests/
│   └── test_etl.py
├── datasets/              # Локальный набор данных, исключённый из Git
├── creds.db               # Локальная база данных с учётными данными, исключённая из Git
├── pyproject.toml
├── .gitignore
└── README.md
```

## ETL-процесс

1. **Extract (Извлечение):** Чтение исходного набора данных об играх Steam из файла Parquet с использованием библиотеки pandas.
2. **Transform (Преобразование):** Приведение типов данных, удаление пропущенных и некорректных значений, удаление дубликатов AppID и выбор до 100 записей.
3. **Validate (Проверка):** Проверка обязательных столбцов, пропущенных значений, уникальности идентификаторов, числовых типов данных и допустимых диапазонов значений.
4. **Load (Загрузка):** Подключение к PostgreSQL и добавление или обновление записей с использованием AppID в качестве первичного ключа.

## Конфигурация

Для работы ETL-процесса необходимы:

- `datasets/games.parquet` — локальный набор данных об играх Steam.
- `creds.db` — предоставленная преподавателем локальная база SQLite с учётными данными для подключения к удалённой базе данных.

Оба файла должны храниться локально и исключены из системы контроля версий Git.

## Запуск

Запуск полного ETL-процесса:

```bash
python -m etl.main --table deebm
```

Дополнительные аргументы:

- `--table` — название таблицы назначения в PostgreSQL (обязательный аргумент).
- `--dataset` — путь к исходному файлу Parquet.
- `--creds` — путь к локальной базе данных SQLite с учётными данными.

Пример запуска:

```bash
python -m etl.main \
    --table deebm \
    --dataset datasets/games.parquet \
    --creds creds.db
```
